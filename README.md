# Mixed Rice Dataset
Built from Nutrition5k dataset, with bounding box labels added.

## Label Format
<class_id> <x_center> <y_center> <width> <height> <mass_g>

Note that mass is ***per-class***, not per object, so every object of a class has the same mass value.
